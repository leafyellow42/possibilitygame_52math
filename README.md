# 가능성 베팅 게임 (5학년 2학기 수학)

초등학교 5학년 2학기 수학 '가능성' 단원 수업용 게임입니다. 교사가 교실 TV에 띄워 진행하고, 학생은 종이 점수표에 기록합니다.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 설치할 것은 없고, 글꼴(`fonts/`)도 함께 들어 있어 인터넷 없이도 그대로 보입니다.

## 구성

- `index.html` — 게임 전체 (홈 화면, 게임 규칙 튜토리얼, 교사용 도움말, 점수표 받기)
- `fonts/neodgm.woff2` — Neo둥근모 글꼴 (SIL Open Font License 1.1, https://neodgm.dalgona.dev)
- `sheets/` — 인쇄용 점수표 PDF (A4)
  - `score-word-20.pdf` 가능성을 글로 쓰기 · 20문제 (A4 반으로 잘라 2명)
  - `score-word-40.pdf` 가능성을 글로 쓰기 · 40문제 (A4 1장)
  - `score-number-20.pdf` 가능성을 번호로 쓰기 · 20문제 (A4 반으로 잘라 2명)
  - `score-number-40.pdf` 가능성을 번호로 쓰기 · 40문제 (A4 1장)

## 게임 진행

1. 문장을 읽어요.
2. 가능성(불가능하다 · ~아닐 것 같다 · 반반이다 · ~일 것 같다 · 확실하다)을 골라요.
3. 문장이 맞을지(O), 틀릴지(X) 점수표에 걸어요. 불가능하다 · 확실하다 문장은 걸지 않아요.
4. 실험(주사위 · 동전 · 회전판 · 공 뽑기 · 카드 뽑기)으로 확인해요.

배점: O = 전체 경우의 수 ÷ 해당하는 경우의 수, X = 전체 경우의 수 ÷ 해당하지 않는 경우의 수 (반올림).
실험 결과는 실제 확률대로 무작위로 정해집니다.
